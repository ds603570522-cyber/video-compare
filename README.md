# 原视频同步对比

一个无需安装前端依赖的本地视频对比播放器。首次打开时不加载任何视频，手动选择或拖入本机视频后即可使用。

## 使用

下载项目后直接用现代浏览器打开 `index.html`。Windows 也可以双击 `打开对比.cmd`。

若需要本地 HTTP 地址，运行 `python serve.py`，然后打开终端输出的网址。服务只监听本机回环地址，不提供视频上传接口。

## 功能

- 最多三个视频同步播放，可多选、拖入、替换或移除。
- 共用时间轴，支持播放/暂停、以 1/60 秒定位、回到开头和循环。
- 显示分辨率、FPS 和时长；MP4 / MOV 的 FPS 读取自视频轨时间信息，可变帧率标为平均值，无法读取时明确显示未识别。
- 并排比较或滑动分界，同步放大查看细节。
- 仅视频画面的全屏模式，底部包含进度、时间、基础播放、声音和退出控制；停止操作约两秒后自动隐藏，拖动进度时保持显示。
- 保留原视频各自的帧率、分辨率、色彩及音轨，不转码、不改写源文件。按同一时间位置同步，共同播放区间以最短视频为准。

## 文件和隐私

选择的视频通过浏览器的本地文件对象读取，不上传服务器，不随项目分发。刷新页面会回到没有视频的初始状态。视频能否播放取决于浏览器对其容器和编码的支持。

项目是独立 HTML 文件，样式和脚本均内嵌，无第三方前端资源。`serve.py` 仅为可选的本地启动工具。
